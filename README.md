# TripSecure – Personal Safety Application

TripSecure is a full-stack personal safety application designed to help users stay connected and protected during travel and everyday activities. It provides emergency SOS alerts, trusted contact management, location sharing, safety-zone information, and incident reporting.

## Features

- User Registration and Login
- One-tap SOS Alert System
- Emergency Contact Management
- Live Location and Map Support
- Safety Zone Information
- Incident and Safety Reports
- Emergency and Transportation Support
- SOS and Incident History
- User Profile and Settings
- JWT-based Authentication
- MongoDB Atlas Integration

## Technology Stack
